# Binder

AG~~I~~M. Artificial General ~~Intelligence~~ Memory.

Binder is a small macOS app and CLI that remembers you, your machines, your hosting and your SSH keys, so a fresh AI session starts out knowing your setup and doesn't ask where the site is hosted. When a session gets long, Binder hands it over to a new one without losing the thread.

It is early. There is a design and a plan, and no code yet.
