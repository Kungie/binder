# Binder 3.9: Servers, and a window that drags

## Servers

The screen is called Servers. Its header names the server in use by its own name (`hostname`, read with the status)
with a chevron; a click opens a list of every server added (`servers` in `config.toml`, each by its SSH target, with
its name as last read in `server_names`), the one in use marked. Picking one makes it `server`, which every screen
that talks to the server uses. Add server takes an SSH target and switches to it. Status read from one server is
dropped when the server changes, so a name is never saved under another server's target.

## Window

The title bars could not move the window: the capability lacked `core:window:allow-start-dragging`, so Tauri refused
every drag. It is granted now, and a press on text inside a drag region (a title, a label) moves the window too;
presses on buttons, fields, links and other controls do not.
