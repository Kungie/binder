# Binder 3.5: Agents like a small herdr

The owner asked for five things on the Agents screen: a strip of the agent's runs, an alert when an agent waits or
finishes, a Claude Code usage counter, a model picker for Ollama with the server's load, and one session per project,
"a simple herdr".

## Layout

- A sidebar on the left lists the sessions, each with a state dot and a word: Working, Waiting, Idle, Exited or Off.
  The main area shows one terminal, the selected session. ⌘1 to ⌘9 pick a session. Terminals that were opened stay
  connected while hidden.
- Sessions: Claude Code at home (`binder-claude`), Ollama (`binder-ollama`, with the chosen model), and one Claude Code
  session per project that has an agent folder (`binder-claude-<slug>`, started in that folder). A project session is
  listed once it runs on the server or the owner adds it with New session. Close ends a project's tmux session.
- The header shows the server's CPU and memory and Claude Code's usage.
- Above the terminal, while there are any, a strip lists the runs that are live or ended in the last 24 hours: the
  task, how long, the last line of output and Stop for a live one.

## State

Every 5 s while Agents shows and every 20 s otherwise, Binder reads each `binder-*` tmux session's foreground command
and visible screen over the shared ssh connection. Claude Code is Waiting when the screen asks a question ("Do you
want", a `❯ 1.` choice), Working when it shows "esc to interrupt", Idle otherwise; a session whose foreground is a
shell is Exited. Going from Working to Waiting or Idle sends one notification ("waiting for you" or "finished"),
unless Binder is in front showing that session.

## Usage

Claude Code's transcripts (`~/.claude/projects/*/*.jsonl`) on the server and on the Mac, from the last eight days, are
read by one awk script that prints each message's time, id and token counts. Each message counts once. Tokens are
input, output and cache writes; cache reads are left out. The header shows the last 5 hours, today and the last 7
days, read once a minute while Agents shows.

## Ollama

The model list comes from `docker exec ollama ollama list`. Picking a model saves it (`ollama_model`, default
`qwen3:4b`), ends `binder-ollama` and opens it again; a model name that isn't installed is pulled by `ollama run`.
Names are letters, digits and `._:/-` only.

## Left out

A usage limit warning: Claude Code doesn't publish the plan's limits. The old `binder-qwen` session is left alone.
