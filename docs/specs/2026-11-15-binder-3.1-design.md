# Binder 3.1

The owner asked for four things after 3.0, and said to ship without asking for approval of spec, plan, push or release.

## What and why

1. **The 11 minor findings from the 3.0 review.**
   - The watch reads the owner's restarts after the fetch, allows a 10 second clock slack, and keeps a gap open when the time read fails.
   - The vault check runs outside the database lock, and a weekly note cut short is removed.
   - GitHub syncs run one at a time, a full page of 200 issues closes nothing, and a renamed repo carries its issue tasks.
   - A failed agent start gives the task back.
   - A failed review says so and stops polling.
   - A failed restart takes back its OwnerRestart.
   - The brief re-reads every 5 minutes and after a manual Sync that changed issues.
2. **Sites made the mouse stutter.** Each card ran a live page at 1280 × 800. Now every card shows a still snapshot, with scripts removed and animations and transitions turned off.
3. **"Vault not connected".** The vault share wasn't mounted after the Mac slept. Binder now mounts it itself with `mount volume`, which takes the Keychain's password. It checks every minute, retries every 10 minutes when the share doesn't answer, and stops after a canceled prompt until Connect. Done today has a Connect button.
4. **New sites show up by themselves.** Every compose project with a cloudflared container is a site, wherever its folder is. A tunnel set up on Cloudflare's side gives its hostname through its log. Only that hostname leaves the server.

## Approaches

- **Previews.** I chose still snapshots for every site. A live frame paused off screen was rejected because a cross-origin page can't be paused. A real screenshot would need a hidden webview and a capture API that Tauri doesn't have.
- **Vault.** I chose `mount volume` with the Keychain password. `open smb://` was rejected because it opens a Finder window. `mount_smbfs` was rejected because it needs the password in hand.
- **Discovery.** I chose cloudflared containers by compose project. Scanning more folders was rejected because it misses token-run tunnels, and Cloudflare's API was rejected because it needs a token on the Mac.

## Plan

One branch, `binder-3.1`. Each fix gets a failing test first, then the code, then the full `make test`. The work is released as 3.1.0, and the site is updated after the release.
