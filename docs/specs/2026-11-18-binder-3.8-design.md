# Binder 3.8: Claude Code's limits in percent

The owner wanted the Agents header to show usage in percent, as Claude Code's `/usage` does, not token sums.

## Source

Claude Code hands its status line the plan's limits (`rate_limits.five_hour` and `seven_day`, each with
`used_percentage` and `resets_at`); Claude Code marks the field as experimental. The first time Agents finds it missing, Binder adds
Binder's status line to the server's `~/.claude/settings.json` (a copy is kept once as `settings.json.binder-backup`):
`sh ~/.claude/binder-statusline.sh`, which writes the input to `~/.claude/binder-limits.json` when it has the limits,
then runs any status line that was there before. Binder never reads Claude Code's credentials.

## Header

With limits kept: `5 h` and `week`, each a small bar and the percent, green under 50, yellow under 80, red above, the
reset time on hover. A window whose reset time has passed reads 0 %. Token sums move to the hover text. Before Claude
Code's next reply after installing, the header says so and keeps the token sums.
