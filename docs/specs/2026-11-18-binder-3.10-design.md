# Binder 3.10: exit nodes and devices on the tailnet

The owner added a VPS to the tailnet and uses it as an exit node, and wants the phone and the Mac on Devices.

## Devices

- The Tailscale panel marks the device this Mac's traffic goes out through with an Exit node chip (`ExitNode` in
  `status --json`; `ExitNodeOption` is read too).
- A device the owner added whose address is a tailnet device's Tailscale address, MagicDNS name (whole or its first
  label) or host name takes its Online or Offline from Tailscale, with a Tailscale note, instead of a TCP probe. A
  phone answers no port, so a probe alone always called it Offline.

## Servers

A server keeps the name it was first given (its hostname on first read, or one written into `server_names`); later
reads no longer replace it. A VPS whose hostname is a provider's serial number can carry a readable name.
