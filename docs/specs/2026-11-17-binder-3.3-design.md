# Binder 3.3

The owner picked five additions: due-time reminders, quick add from anywhere, site uptime history with down alerts, disk warnings, and a simple pomodoro in the menu bar. They said to ship without asking for approval.

## Decisions

- **Reminders.**
  - Only tasks with a due time are reminded, at that time, each once per due time.
  - Moving the time arms the reminder again.
  - A reminder more than a day late is dropped, so waking the Mac doesn't bring a flood.
- **Quick add.**
  - Control-Option-N works anywhere, and New task in the menu bar does the same.
  - Both open a small window with one line of input, parsed as it's typed in English or Turkish.
  - Parsing is done in the interface, so the preview chips and the created task always agree.
  - Rejected: parsing in Rust, because the chips would need a round trip on every keystroke.
- **Uptime.**
  - Each site is checked from the Mac every 5 minutes, and each check is kept for 8 days.
  - A site counts as down after two failures in a row, so a single blip isn't news.
  - Sites shows the last week as 28 six-hour bars.
- **Disks.**
  - The server disk and the SD card are checked every minute with the existing server read.
  - A disk warns once when it passes 90 % and is forgotten again below 85 %.
  - There is no backup check, because Binder has no idea of a backup yet.
- **Pomodoro.**
  - The cycle is 25 minutes of focus, then a 5 minute break, and a 15 minute break after every fourth focus.
  - A break starts by itself, and the next focus waits for the owner.
  - The time left shows beside the menu bar icon, and a sound plays at each change.
  - The menu shows how many focus sessions finished today. There's nothing to set up.
  - Rejected: linking a pomodoro to a task, to keep it simple.

## Plan

One branch, `binder-3.3`. Every part gets core tests first, then the code. It ships as 3.3.0, and the site is updated after the release.
