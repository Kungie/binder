# Binder 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detailed catch cards, destinations on cards, project topic notes, in-app edit and delete, usage counts, hosting and server notes, machines for homelab hosts, and images and PDFs from sessions.

**Architecture:** Note and proposal formats grow backwards-compatibly: new fields decode with `decodeIfPresent`, and decision details are indented lines under their decision. New BinderCore units are `Topics.swift`, `UsageStore.swift` and `FileCatch.swift`. Capture, the summarizer, the card builder and the graph read them. The UI work sits in `ProposalCard`, `NoteView`, `LibraryModel` and `SettingsView`.

**Tech Stack:** Swift 6 tools, Swift 5 mode, SwiftUI, macOS 14, Swift Testing. No third-party dependencies. ImageIO and PDFKit come from the SDK.

**Spec:** `docs/specs/2026-11-04-binder-1.1-design.md`

## Global Constraints

- Everything Binder shows or writes is English, whatever language a session is in.
- Only the Command Line Tools: build and test with `make build` and `make test [FILTER=...]`. Never write `@State`; use `@StateObject private var x = Local(value)`.
- New Codable fields decode with `decodeIfPresent` and a default, so older inbox, state and session files still load.
- Every file and fact still goes through Keep. Secrets are never stored: run `SecretFilter.redact` on model output and `SecretFilter.containsSecret` on new text before saving.
- Binder never writes to `~/.ssh` and never opens private keys.
- Copy rules: short sentences, no exclamation marks, no em dashes.
- Commit after every task with a conventional message and no attribution lines. Push only when the user says so.

## Review Focus

1. **Project names with spaces or dots** (`Personal Site`, `Bib.`) as topic folders and file folders: paths must work and wikilinks must resolve. Covered in Task 3 (`topicPathsForOddProjectNames`) and Task 12 (`keepFileIntoOddProject`).
2. **Hand-written indented lines** under a decision in Obsidian are treated as that decision's detail and move with it. They must never be lost on supersede, restore or delete. Covered in Task 1 (`handWrittenSubBulletsTravel`).
3. **Hostile or odd model output**: `"topic": "../../etc"`, `"also": ["servers/../me"]`, empty strings, or non-string types. These must be ignored, never turned into paths. Covered in Task 2 (`reviewIgnoresUnsafeTopicAndAlso`).
4. **Transcripts full of screenshots** in tool results, and huge base64 blobs. They must be skipped without the hook blowing its time or memory budget. Covered in Task 11 (`toolResultImagesAreIgnored`, `oversizedAttachmentSkippedWithoutDecoding`).
5. **A cached card on SessionStart** must still record usage exactly once per session. Covered in Task 9 (`cachedCardStillRecordsOnce`).
